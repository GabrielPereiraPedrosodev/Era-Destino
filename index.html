Regras para viajar no tempo

Para não causar problemas na história, os viajantes precisam seguir algumas regras.

  • Não alterar acontecimentos históricos.
  • Não levar objetos para outra época.
  • Não revelar informações do futuro.
  • Não se atraze para o embarque.
  • Não se atraze para a saida ou ficara no local!.
  • Não sair do local designado.
  • Seguir as orientações do guia!.
  • Caso não siga as orientações, poderá entrar em perigo.
  • É A MAIS IMPORTANTE NÃO SE ESQUEÇA DAS REGRAS!
